## 2-B. 표현 기획
- 한 줄 콘셉트: **«화면 하나가 곧 바탕화면» — 도트 고양이가 사는 바탕화면 위를 카메라가 돌아다니며, 고양이의 하루(걷기 → 클릭 → 공부 → 졸기 → 기록 → 이사)를 따라간다.**
- 훅 시안
  - ① 화면을 꽉 채운 거대한 도트 고양이 얼굴(픽셀이 보일 만큼) → 카메라가 쭉 빠지면 바탕화면 구석 작업 표시줄 위의 작은 펫 + «내 바탕화면에 공부 친구가 산다» — 크기 대비 · 정체 공개
  - ② 브라우저 탭 수십 개에 묻힌 타이머 → 고양이가 탭을 밀어내며 등장 — 공감형이지만 1초 안에 안 읽힘
  - ③ 거대한 `01:24:15` 숫자 → 말풍선으로 줄어듦 — 깔끔하지만 «무엇인지»가 늦게 드러남
  - → 고른 것: **①** — 픽셀 아트 자체가 가장 센 그림이고, 빠지는 카메라 한 번에 «바탕화면 펫»이라는 정체가 드러난다.
- 시각 방향: **«도트 게임 화면»** — 짙은 남색 `#1E2136` / 카드 `#2B2F4A` 바탕, 인디고 `#4F46E5` · 노랑 `#FFD166` 강조, 크림 `#FFF8E6` 글자, 바탕화면은 픽셀 격자 무늬 + 레트로 창 테두리. 제목 · 본문 글꼴 모두 **Galmuri11**(실제 앱 글꼴 · OFL) — 앱 화면과 영상이 같은 글자로 보이게. 작은 노트 · 영문 보조는 Pretendard.
- 키트: **팝** — 액션 분위기 «경쾌» + 통통 튀는 도트 캐릭터와 맞음.
- 킥 장치: **빨리 감기** (장면 4) — 고양이가 조는 동안 시계가 0:00 → 10:00 으로 휙 감기고(배속 · 화면 줄무늬), 딱 멈추며 자리 비움 확인 창이 뜬다. «10분 입력 없음»이라는 원문 숫자를 그대로 보여 주는 장치. 버린 후보: 아니지~ 다시(«브라우저 탭 타이머 vs StudyPet» — 1분 안에 두 줄기를 넣기엔 길다) · 멈추고 짚기(장면 2 클릭 순간 — 등장 리듬이 단조로워질 뿐 기억에 남는 한 방이 아님).
- 그림 재료: 스프라이트 프레임(실물) + 코드로 그린 바탕화면 · 작업 표시줄 · 액션 카드 · 확인 창 · 차트 · 폴더/USB 아이콘.
